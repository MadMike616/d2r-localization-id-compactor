1.1.0
- Require an explicit choice to preserve item-runes.json IDs for existing saves
  or compact its custom IDs for a clean mod with no character/shared-stash saves.
- In preserve mode, keep item-runes.json unchanged and reserve 1000 numbers
  above and below every one of its IDs when assigning other custom ranges.
- Move any overlapping consecutive range as a whole to a safe multiple of 1000.
- Include the selected mode, reserved ranges and preserved item-runes records
  in the preview and backup reports.

1.0.2
- Store backups and JSON reports outside localization and game-data folders.
- Prevent backup destinations inside game data or the vanilla reference tree.
- Offer relocation of verified legacy compactor backups during apply, including
  when all active IDs are already compacted.
- Allow selecting an external backup folder interactively or with --backup-folder.

1.0.1
- Command-line option names accept any letter case.
- The apply confirmation accepts any letter case and surrounding spaces.

1.0.0
- Portable localization ID compaction with vanilla preservation, preview,
  mandatory verified backups, ID mappings and rollback on write failure.
